# TAG TEAM — الاستنزاف | ROUND 01

عرض سينمائي تفاعلي لمسابقة حقيقية: شاشة جمهور 16:9 + لوحة تحكم بالجوال، مع مزامنة بين الجهازين.

## التشغيل
افتح `index.html` على الجهازين واختر دور كل جهاز (شاشة الجمهور / لوحة التحكم).

- داخل claude.ai (Artifact): المزامنة عبر room + db الخاصة بالـ Artifact.
- على GitHub Pages أو أي استضافة: المزامنة عبر MQTT على وسيطين عامين (EMQX و HiveMQ) برمز غرفة.
  لوحة التحكم تعرض رمز الغرفة ورابط الجمهور: `index.html?room=CODE#screen`.

## الملفات
- `js/logic.js` منطق الراوند (مؤقت شطرنج، إجابات، تبديل، تراجع، فوز)
- `js/sync.js` المزامنة
- `js/screen.js` مخرج المشاهد على شاشة الجمهور
- `js/control.js` لوحة التحكم
- `js/questions.js` بنك الأسئلة الافتراضي (50) — قابل للتعديل من الإعدادات

صور المشاركين منشورة بموافقتهم.
