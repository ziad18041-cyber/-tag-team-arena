# Replaced character image collection

هذا الأرشيف يحتوي على 20 لاعب كرة قدم و20 شخصية.

تم استبدال الشخصيات التي لم يثبت توفر صور لها بالبدائل التالية، مع تقسيم تقريبي للصعوبة التعليمية:

- Easy: The Tramp — Charlie Chaplin، Sherlock Holmes، Dracula — Bela Lugosi، Frankenstein’s Monster، James Bond، Indiana Jones، Rocky Balboa، Forrest Gump، Popeye، Betty Boop.
- Medium: The Joker، Batman، Wonder Woman، Wednesday Addams، The Doctor.
- Hard: Don Vito Corleone — The Godfather.

ملف Sources_and_Licenses.csv يضم المصدر الأصلي والترخيص ونص الإسناد لكل ملف. لا توجد كتابة مضافة أو صور مولدة بالذكاء الاصطناعي. راجع شروط الترخيص، وانتبه إلى أن تراخيص الصورة لا تحسم بالضرورة حقوق الشخصية أو العلامة التجارية أو حقوق الصورة الشخصية. بعض ملفات الملكية العامة قد تكون ملكية عامة في الولايات المتحدة تحديدًا، وقد تختلف النتيجة حسب بلد الاستخدام.

ملاحظة: بعض الصور الأصلية للاعبي كرة القدم تحتوي شعارات أو أرقامًا على الملابس الرياضية، لكنها لا تحتوي أسماء أو عناوين مضافة على الصورة.
